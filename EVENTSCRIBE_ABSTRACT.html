EventScribe

An AI-assisted platform for generating polished, editable academic event reports from event facts, photographs, and reference formats.

Akshansh SinghURN: 2581285
Kumar NishkarshURN: 2581286
Sumedha RawatURN: 2581030

Abstract

Academic event reports are repetitive and time-consuming to prepare because professors must manually reproduce headings, formatting, image placement, and formal content for every event. EventScribe addresses this problem through a web-based workflow in which a professor provides event facts, photographs, and either a reference PDF/DOCX or a written description of the desired format. The system analyzes the requested structure into a validated format specification, generates fact-grounded report content, and uses a deterministic document-rendering pipeline to produce editable DOCX and PDF files. Users can review, edit, download, and revisit reports from authenticated history. By separating AI-assisted format understanding and content drafting from Python-based validation and rendering, the project aims to provide reliable, testable, explainable, and reusable academic documentation.

Problem Statement

Manual report creation requires repeated formatting work and is prone to inconsistent structure, missing details, incorrect image placement, and export errors. A single hardcoded template cannot serve departments with different report requirements.

Objectives

  • Reduce the time required to create submission-ready reports.
  • Understand flexible PDF, DOCX, and text-based formats.
  • Generate content only from supplied event facts.
  • Produce editable DOCX and readable PDF outputs.
  • Provide secure authentication, history, downloads, and clear errors.

Proposed Methodology

The application validates user inputs, extracts the structure of a reference format, and stores it as a versioned specification. An AI service drafts structured report content, while backend validation checks required fields and prevents unsupported claims. A deterministic renderer then applies headings, metadata, sections, images, margins, and page-break rules to create DOCX and PDF outputs. Authenticated report records are stored for later access.

Expected Outcomes

  • A working professor-facing report-generation web application.
  • Consistent DOCX/PDF reports with dynamic format support.
  • Reduced manual formatting effort and fewer submission errors.
  • Testable AI-to-rendering separation with transparent failures.
  • Reusable report history and downloadable outputs.
